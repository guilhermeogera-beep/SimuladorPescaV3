🔗 Conexão GitHub

Guarda o token que sincroniza calibração, curvas e configurações na nuvem. Configure SÓ neste computador de edição — o totem só lê, não precisa de token.
1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained
2. Repository access: Only select repositories → SimuladorPescaV3
3. Permissions: Contents → Read and write
4. Gera o token, copia e cola aqui em cima.
⚠️ Nunca suba o token pro GitHub nem coloque dentro dos arquivos do site. Ele fica só neste aparelho. Se vazar, revogue e gere outro.
